# lknpd

TypeScript-клиент неофициального API [«Мой налог»](https://lknpd.nalog.ru/) для самозанятых:
регистрация доходов (чеков), аннулирование, поиск и печатная форма.

> 🚧 В разработке. Пакет ещё не опубликован.

- Без runtime-зависимостей: Node ≥ 20, bun, серверный рантайм Next.js.
- Ошибки различают «запрос точно не ушёл» и «запрос мог дойти» — основа защиты от
  двойного чека.
- Поиск ранее созданного чека для сверки после сетевого сбоя.

API неофициальный: ФНС может изменить его без предупреждения.
